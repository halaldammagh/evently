# 🎉 Evently App
<img width="1920" height="1440" alt="468shots_so" src="https://github.com/user-attachments/assets/4046ac2f-9fc0-4954-8bc7-7880990c98cf" />

A modern event management mobile application built using Flutter, designed to provide users with a smooth and intuitive experience for discovering and organizing events.

---

## 📌 Problem Statement

Many event applications suffer from poor user experience and cluttered interfaces, making it difficult for users to discover, explore, and manage events efficiently.

---

## 💡 Solution

This application provides a clean, user-friendly interface combined with a scalable architecture to simplify the event experience. It focuses on usability, performance, and maintainability.

---

## ✨ Key Features

* 📅 Event Listing & Browsing  
* 🔍 Search Functionality  
* 📝 Event Details View  
* ❤️ Favorites System  
* 📱 Clean & Responsive UI  
* ⚡ Fast and smooth performance  

---

## 🧱 Architecture

The project follows **Clean Architecture** principles to ensure scalability and maintainability.

```
lib/
├── core/
├── features/
│   ├── onboarding/
│   ├── home/
│   ├── event/
│   └── favorites/
```
